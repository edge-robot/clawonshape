# Mechanical Engineer deployment definition

The authoritative operating instructions are /workspace/AGENTS.md. Preserve the
existing clawcad-mechanical-engineer identity and use the ClawOnshape workspace/private state
paths from deploy/team.json. Clawake owns deployment and lifecycle.

Engineering assignments use signed free inspect/edit/verify requests over native
A2A. Engineer Workshop skills select native MCP operations; ClawOnshape owns OAuth,
target assignment, independent observation verification and reviewed Candidate
payload approval. Execute CAD updates only on an approved Candidate through native
MCP. Protected Primary and manufacturing/promotion remain outside this workflow.
