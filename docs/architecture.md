# Architecture

A single native plugin registers one optional tool and an operator CLI. The plugin manifest owns JSON configuration validation and UI hints. Registration binds exact agent, authenticated requester, channel and channel-account identities. Execution rechecks the live host configuration, invocation authority when available, and private credential state before each request and before returning results. A logical connection cannot belong to unrelated requester identities.

`config.ts` validates immutable bindings and target constraints. `rest.ts` constructs only three fixed GET endpoints under `https://cad.onshape.com/api/v10/`: document, document workspace list, active-workspace elements. No URL, token, document or workspace is accepted from agent arguments. Workspace membership is verified against the provider. Responses contain identifiers only; raw bodies, names, headers and exceptions are omitted. `http.ts` rejects redirects, bounds streaming responses and applies a ten-second deadline without retries.

`oauth.ts` implements the inspected Onshape confidential application authorization-code contract, scoped only to REST Read. `credentials.ts` delegates secret reads/atomic writes to the native SDK with explicit symlink rejection and plugin checks for private ownership/modes/parents. Credential records bind the authenticated requester/channel/account fingerprint; reassigning a connection reference through configuration cannot expose old credentials to a different requester. Credentials are private files, not config/session extensions. Connection lifecycle writes use an exclusive lock held throughout consent, including draining callbacks on timeout; stale locks fail closed. Expiry/401 requests reconnection rather than risking concurrent refresh rotation. The CLI has a short-lived loopback callback listener, not a deployed service.

`mcp.ts` uses the verified native `openclaw mcp probe <server> --json` command for operator metadata discovery. Its adapter consumes only names/diagnostic presence and disables every catalog entry. It exports no actual call path. Native MCP credentials are never read by the plugin. Native MCP server configuration outside the plugin is an independent authority surface: the deployed agent must keep it disabled. Discovery in a separate operator profile is not a tool execution security boundary for another runtime.

Document, protected primary workspace and active workspace are host-configured preferences. The user can select an existing experimental workspace; the tool checks its membership. `validateTarget` rejects any primary write before rejecting all remaining writes. Future native branching/version/merge paths must use Onshape state and reliable target/concurrency contracts. No local revision history exists. Merge has no implementation or approval parser, because authenticated human/Robotics Lead authorization has not been established.

Clawake owns installation, configuration reconciliation and restarts. Mechanical Engineer reasoning and existing OpenClaw A2A delegation remain unchanged. Missing trusted requester identity on delegated turns denies the tool. A later verified host identity propagation contract is required to enable that flow safely.

The first distribution model is an operator-controlled Linux host and an operator/company registered Onshape application. Broad public distribution needs verified PKCE/public-client support or an independently approved onboarding design; embedding a shared secret is excluded. Native Control UI tabs exist but require an experimental lab and additional secure interaction work. Configuration UI hints and CLI are the implemented alternative. No native REST OAuth provider or click-to-connect integration is asserted.
