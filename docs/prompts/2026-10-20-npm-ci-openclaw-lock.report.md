## Open points and risks

1. **Install scripts are not run (npm 11 `allowScripts`).**
   - npm 11.19.1 in the container has `allow-scripts = [""]` and
     `strict-allow-scripts = false`.
   - Because of that, npm did not run these 5 install scripts. They did not fail;
     `npm install` and `npm ci` warn and exit 0.
     - `openclaw@2026.9.9`: `preinstall-package-manager-warning.mjs` and
       `postinstall-bundled-plugins.mjs`
     - `esbuild@0.28.2`: postinstall
     - `koffi@3.3.1`: install
     - `protobufjs@7.6.6`: postinstall
     - `@google/genai@2.23.0`: no-op preinstall
   - I did not run `npm install-scripts approve`. That command would write an
     `allowScripts` policy, which is out of scope and an architect decision.
   - Typecheck, tests and the native-file check pass without these scripts. Approving or
     denying them is a decision for the architect.
2. **`npm audit` reports 5 vulnerabilities (2 moderate, 3 high)** in the OpenClaw
   dependency tree. They are dev-only, and the plugin does not bundle them. I did not run
   `npm audit fix`, because it would change other dependency versions.
3. **Install footprint.** About 812 MB in `node_modules` and 570 lockfile entries. This
   slows down `npm ci` on fresh machines and in CI.
4. **`test:native-files` now passes in the container.** Earlier reports and the agent
   memory treated exit 1 (`native_private_file_sdk_unavailable`) as expected. That
   expectation is now outdated.
5. The prompt's list of foreign changes is incomplete. The working tree also contains
   the untracked `docs/reviews/` and `scripts/__pycache__/`. I left both untouched.
